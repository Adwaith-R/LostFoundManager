
# Lost & Found Manager

A simple Android application developed using Java and XML that helps users report lost and found items.

## Features

- Report lost items
- Report found items
- View all reported items
- Search for items
- Delete reports
- View lost and found statistics
- Offline data storage using SQLite

## Technologies Used

- Java
- XML
- Android Studio
- SQLite Database

## Application Screens

1. Home Dashboard
2. Report Lost Item
3. Report Found Item
4. All Reported Items
5. Search Items

## Database

The application uses SQLite to store item information locally on the device.

## Installation

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization.
4. Run the application using an Android emulator or device.
